# @paw 🪽

Кнопка в трее macOS для быстрого включения и выключения VPN.

## Возможности

- Левый клик — включить/выключить VPN
- Правый клик — меню: выбор VPN из системных подключений, тема, запуск при входе, выход
- Цвет иконки показывает статус подключения, цвета задаёт тема: steel, halo, moon, garden, blood
- Выбранные VPN и тема запоминаются между запусками

## Установка

1. Скачай `paw-x.y.dmg` из [Releases](../../releases) и открой.
2. Перетащи `@paw 🪽` на ярлык «Программы» и извлеки образ.
3. Приложение не нотаризовано, поэтому при первом запуске macOS его заблокирует. Открой через «Системные настройки → Конфиденциальность и безопасность → Всё равно открыть».

Автозапуск: правый клик по иконке → «Запускать при входе».

## Сборка

Нужен Xcode 16 или новее.

1. Открой `paw.xcodeproj`.
2. Выбери схему `paw › My Mac`.
3. Cmd+R.

### DMG для релиза

1. В Xcode: Product → Archive → Distribute App → Custom → Copy App.
2. `scripts/make-dmg.sh путь/к/paw.app` — образ появится в `build/paw-<версия>.dmg`.

Фон окна берётся из `assets/dmg-background@2x.png` (1200×800). Раскладку окна выставляет Finder, поэтому при первом запуске macOS спросит, можно ли терминалу управлять Finder.

## Как работает

Статус и переключение идут через системный фреймворк SystemConfiguration (`SCNetworkConnection`). Приложение подписывается на изменения статуса выбранного VPN и включает/выключает его само, без запуска сторонних команд.

## Ограничения

- macOS 15.1+.
- VPN на базе Outline (например, PepperVPN) не дают включать себя извне — их нужно включать из их собственного приложения.
